# Icon and logo attribution

## Fedora marks

`status/fedora_logo.svg` and `status/fedora_wordmark.svg` were drawn for this project.
They are **not** copies of the files in Fedora's `fedora-logos` package, which ships under
a restricted licence (`LicenseRef-Fedora-Logos`) granting redistribution only as part of an
approved Fedora spin - a portfolio site does not qualify.

- `fedora_logo.svg` is original SVG geometry (a stroked path set) reproducing the Fedora
  infinity-f mark, filled with Fedora Blue `#3C6EB4`.
- `fedora_wordmark.svg` is the word "fedora" set in **Comfortaa Light** and converted to
  outlines. Comfortaa is by Johan Aakerlund, licensed under the SIL Open Font License 1.1.

Fedora(R), the Fedora word design, and the Infinity design logo are trademarks of Red Hat,
Inc. They are used here referentially, to identify the visual theme this site imitates.

See https://fedoraproject.org/wiki/Legal:Trademark_guidelines

## Interface icons

The remaining icons under `apps/`, `status/`, `system/` and `window/` were inherited from
the upstream project this portfolio was forked from. The directory is named `Adwaita` after
the GNOME icon theme that Fedora Workstation ships, but the files themselves have not been
replaced with upstream Adwaita assets.
